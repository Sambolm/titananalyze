TITAN ANALYZE — IPHONE INSTALL PACKAGE

UPLOAD
1. Upload every file in this folder to the same GitHub Pages repository.
2. Make sure index.html is in the repository root.
3. Open the HTTPS GitHub Pages address in Safari on your iPhone.

INSTALL ON IPHONE
1. Tap Safari's Share button.
2. Tap Add to Home Screen.
3. Confirm the name Titan Analyze and tap Add.

IMPORTANT
- Microphone recording requires the app to be served through HTTPS.
- GitHub Pages provides HTTPS.
- The app icon, standalone display, and offline shell are included.
- iPhone may still require microphone permission the first time you record.
- Recording laws vary by location. Inform participants and obtain required consent.
