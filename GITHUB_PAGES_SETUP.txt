TITAN ANALYZE — GITHUB PAGES DEPLOYMENT

IMPORTANT:
Do NOT upload this ZIP file as a single file and expect GitHub Pages to run it.
Extract the ZIP first, then upload the CONTENTS of the extracted folder to the repository root.

The repository root should contain:
- index.html
- manifest.webmanifest
- service-worker.js
- titan-robot.png
- apple-touch-icon.png
- icon-192.png
- icon-512.png
- icon-1024.png
- .nojekyll
- README.txt
- AI_SETUP.txt
- AI_ENDPOINT_RESPONSE_EXAMPLE.json

GitHub Pages:
1. Open your repository.
2. Upload all extracted files to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose:
   Source: Deploy from a branch
   Branch: main
   Folder: /(root)
5. Save.
6. Open the HTTPS Pages URL once GitHub shows the deployment as active.

IPHONE:
Open the Pages URL in Safari > Share > Add to Home Screen.

AI:
The app itself will run without an AI endpoint.
Automatic transcription/analysis requires a private HTTPS endpoint entered under Settings > AI Analysis Service.
